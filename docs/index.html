02. Lyrics Agent

The system taps into LRCLIB for perfectly timed, human-verified `.lrc` sync files. If missing, it pivots to Genius and uses an LLM to predict timestamps.

03. Image Agent

For every lyric line, an LLM constructs an aesthetic search query to scrape high-quality imagery matching the mood.

MoviePy stitches the LLM images, text timings, and audio into the final output.
